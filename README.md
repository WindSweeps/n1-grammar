# 文法の森 · N1 语法思维导图

面向中文学习者的日语 N1 语法学习页：12 个语义分支、108 个学习条目，以及 8 组易混辨析。包含少量跨级衔接项，不是官方完整考纲。中文讲解与例句为本项目编写，语法卡片附参考来源。

## 使用

直接用浏览器打开 `index.html`。页面内置内容、样式和脚本，不依赖外部资源。学习进度保存在当前浏览器，可在“使用指南”导出和导入。

手机端提供底部导航、全屏语法卡、固定返回与学习操作。浏览器返回键可退出语法卡、自测或指南；分类与列表位置会恢复。前后切卡保留打开时的学习队列，不受本轮掌握或收藏状态变化影响。

搜索默认在当前分类内进行，可点击“搜索全部分类”扩大范围。自测开始前可选择当前范围、全部待学、全部收藏或所有语法，每轮最多 10 条。

日文语法名称、例句及讲解中的日语引用默认显示振假名。页头、手机详情和自测窗口均可切换“注音：开／关”，选择保存在当前浏览器；中文说明不标日语读音。

## 编辑与构建

```sh
python3 build.py
python3 -m http.server 8766 --bind 127.0.0.1
```

- `data/a.json`、`b.json`、`c.json`：语法内容与参考链接。
- `data/readings-*.json`：对应条目的人工注音，格式为 `[汉字|かな]`；构建时校验还原后与原文一致，以及例句汉字的注音覆盖。
- `index.html.in`：页面结构和基础样式。
- `mobile.css`：手机与平板交互布局。
- `app.js`：学习状态、导航历史、搜索和自测。
- `build.py`：验证内容并生成完整的 `index.html`。

修改源文件后需要重新构建并提交 `index.html`。仅打开生成后的 `index.html` 即可使用；模板不是可运行入口。

## GitHub Pages

发布源为 `codex/publish` 分支的根目录 `/`，`.nojekyll` 保持页面原样发布。页面不收集登录信息，不将学习进度发送到服务器。

本地预览与 GitHub Pages 使用不同的浏览器存储空间。要迁移原学习进度，先在原页面导出，再在新网址导入。
